把阶段定位迁移到乘积的消费者

第 6 天 · P3-C1 · LLVM 22.1.8

机制问题

同一乘积交给两个不同的消费者，怎样查明最终运算形态在哪个阶段确定？

本节产出为两幅数据依赖草图、一份带截点的预测和一条复核路径。

先练习区分两个截点

第 3 天的已测宽加法提供了读日志的方法：GlobalISel 在 instruction-select 后有 ADCSXr，在 aarch64-post-select-optimize 后出现 ADCXr。二者都读取 NZCV；后者省去不再需要的标志写入。若只读最终汇编，就无法从这条指令确定变化发生在哪一遍。

这次回到 SelectionDAG。两个函数都做无溢出标志的 i64 乘法，低 64 位乘积只有一个使用者。先从 IR 画出谁定义结果、谁消费它，再分别预测刚完成选择和最终汇编中的依赖。观察目标指令时连同操作数一起读：固定零寄存器和活跃的累加值有不同的含义。

独立定位与预测

完整输入 day6-multiply.ll

define i64 @product_sum(i64 %x, i64 %y, i64 %a) {
  %p = mul i64 %x, %y
  %r = add i64 %p, %a
  ret i64 %r
}

define i64 @product_xor(i64 %x, i64 %y, i64 %a) {
  %p = mul i64 %x, %y
  %r = xor i64 %p, %a
  ret i64 %r
}

从 AArch64InstrInfo.td 搜索乘法的汇编拼写，沿定义或别名找到输入操作数，再到 AArch64InstrInfo.cpp 搜索对应的机器 opcode，检查哪些调用点读写乘积的使用者。先写下你选的符号和理由，再打开输出。

作答后的阶段核对

从项目根目录运行。先用 "${LLC:-llc}" --version 核对 22.1.8。脚本固定 Linux AArch64、generic、-O2、SelectionDAG 和机器指令验证器。需要指定工具时先设置 export LLC=/opt/homebrew/opt/llvm@22/bin/llc。

bash experiments/replay-selection.sh 6

打开 evidence/day6/selection.txt，按函数名定位选择后的机器基本块，再在同目录 final.s 中找到对应函数。

"${LLC:-llc}" -mtriple=aarch64-unknown-linux-gnu -mcpu=generic -O2 -global-isel=0 -fast-isel=0 -verify-machineinstrs -filter-print-funcs=product_sum -print-after-all experiments/day6-multiply.ll -o /dev/null 2> evidence/day6/stages.txt

若两个截点形态不同，在 stages.txt 中找首次满足你的判据的机器基本块，再返回前一个 dump 检查操作数。
