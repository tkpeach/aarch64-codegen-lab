用边界反例检验立即数条件

第 5 天 · P2-C3 · LLVM 22.1.8

机制问题

如何分别检验立即数对齐和字段容量这两个条件？

本节产出为一张四行预测表及两个可证伪的判断。

从已测结果提出可检验的条件

第 4 天在相同配置下测得 4095 与 4096 都进入 ADDXri，4097 则在 ADDXrr 前准备寄存器。把 K 写成十六进制：0xfff、0x1000、0x1001。试着分别检查低 12 位和右移 12 位后的余数值。某个立即数形式无法表示 K，仅能排除这一条形式；替代序列仍须实测。

从 AArch64InstrInfo.td 的 defm ADD 跟到 AArch64InstrFormats.td 的 AddSub，比较 Xri 与 Xrr 的输入。沿立即数操作数定义查找移位选择与立即数字段，把字段限制对应到具体 K。

两组只改常量的输入

完整输入 day5-add-imm.ll

define i64 @plus_8192(i64 %x) {
  %sum = add i64 %x, 8192
  ret i64 %sum
}

define i64 @plus_8193(i64 %x) {
  %sum = add i64 %x, 8193
  ret i64 %sum
}

define i64 @plus_16773120(i64 %x) {
  %sum = add i64 %x, 16773120
  ret i64 %sum
}

define i64 @plus_16777216(i64 %x) {
  %sum = add i64 %x, 16777216
  ret i64 %sum
}

第一组用 8192 与 8193 检查低位，第二组用 16773120 与 16777216 检查高位。沿用发布版工具链做输入变体对照。先完成下方预测并保存，再运行复验。
