## 评价、核对依据与可选评分

评估为 **1/3，needs_review**。四道主练习有可读取的原答，减法热身未答。已识别 DAG opcode 和指令选择阶段，匹配条件及其证据仍需补齐。

1. **构图，部分正确。** 两个 opcode 和两者的 `i64` 结果类型正确。`add` 经 `SelectionDAGBuilder::visitBinary`，`shl` 经 `visitShift`。后者查询目标移位量类型并按需转换。操作数关系为 `SHL(b, 3)`，随后 `ADD(a, SHL 的结果 0)`。[构图源码](https://github.com/llvm/llvm-project/blob/ca7933e47d3a3451d81e72ac174dcb5aa28b59d1/llvm/lib/CodeGen/SelectionDAG/SelectionDAGBuilder.cpp#L3684-L3720)
2. **选择，部分正确。** 指令选择确实是本例识别折叠的位置。64 位 shifted-register 形式由 `AddSub` 的 `Xrs` 与 `arith_shifted_reg64` 支持。对于本例的普通移位路径，`SelectShiftedRegister` 识别移位类型和常量移位量，编码后调用 `isWorthFoldingALU`。基线选出 `ADDXrs`，最终汇编为 `add x0, x0, x1, lsl #3`。[TableGen 定义](https://github.com/llvm/llvm-project/blob/ca7933e47d3a3451d81e72ac174dcb5aa28b59d1/llvm/lib/Target/AArch64/AArch64InstrFormats.td#L3119-L3126) · [操作数选择](https://github.com/llvm/llvm-project/blob/ca7933e47d3a3451d81e72ac174dcb5aa28b59d1/llvm/lib/Target/AArch64/AArch64ISelDAGToDAG.cpp#L893-L915)
3. **验证，部分正确。** 正确指出要核对一条还是多条。应先看 `-print-after=aarch64-isel` 的机器指令，再看最终汇编。若选择后出现独立移位和普通加法，就会推翻“在该阶段已折叠”的判断。原始证据位于 `evidence/day1/isel.txt` 和 `evidence/day1/add-shift.s`。
4. **变体，IR 无效。** 本地 `llc` 在解析阶段就报 `'%a' defined with type 'i64' but expected 'i128'`。加法的两个操作数仍是 `i64`，且结果若为 `i128`，也无法用题面中的 `ret i64 %sum` 返回。

### 第 4 题复评

修订已让函数返回类型和 `ret` 都使用 `i128`，预期的加法结果宽度与返回端一致。输入端仍不匹配。`%a` 由函数参数定义为 `i64`，`%shifted` 由 `shl i64` 产生，而 `add i128` 要求两个 `i128` 操作数。用基线的 LLVM 22.1.8 参数复跑，解析器仍报 `'%a' defined with type 'i64' but expected 'i128'`，因此这版尚未进入指令选择。第 4 题仍未通过，整体保持 **1/3，needs_review**。

把运算改成 `i128` 可以成为位宽和合法化的实验。若要检查本题的 shifted-register 匹配条件，可保持参数、运算和返回都是 `i64`，将移位量 `3` 改成一个运行时 `i64` 参数，再说明你预期在哪个阶段看到差异。

### 第 4 题第二次复评

**IR 有效，位宽对照成立，实验假设待补。** 参数、移位、加法和返回都改成了 `i128`，统一改变的是运算位宽。移位量仍为常量 `3`。用 LLVM 22.1.8 和基线的 triple、CPU、优化级别实测，`-verify-machineinstrs` 通过。选择后是 `EXTRXrri`、`ADDSXrs`、`ADCXr`，最终对应以下三条计算指令。

```asm
extr  x8, x3, x2, #61
adds  x0, x0, x2, lsl #3
adc   x1, x1, x8
```

宽结果需要处理跨半部移位和低位加法进位。低 64 位依然折叠成带移位的加法。因此这组对照能回答位宽变大是否使整个表达式需要多条指令。要把第 4 题答完整，请补一句你想检验的条件和预期观察。若条件是常量移位量是否必要，需要改移位量而保持位宽固定。整体保持 **1/3，needs_review**，第 1–3 题的缺口仍在。
